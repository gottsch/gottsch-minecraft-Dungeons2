**Dungeons2** is a Minecraft mod that builds sprawling, multi-floor dungeons deep underground, full of monsters, traps, treasure and secrets, with a boss waiting at the bottom.

![Inside a Dungeons2 dungeon](https://raw.githubusercontent.com/wiki/gottsch/gottsch-minecraft-Dungeons2/images/curseforge/dungeon_1.png)

> The 3.0.0 source is on the [`1.20.1-main`](https://github.com/gottsch/gottsch-minecraft-Dungeons2/tree/1.20.1-main) branch. This branch holds the 1.12 code.

## Features

- Dungeons of **one to five floors**, in almost every overworld biome
- Rooms and corridors in **many styles**, generated and hand-built side by side
- **Weathered** stone, cobwebs, roots, lichen, and fungus that isn't always just fungus
- The dungeon's **own monsters**, which change as you go deeper
- A **boss** at the bottom of every dungeon, in a room you can't dig out of
- **Treasure** that improves with depth: chests, weapon racks, pots, sealed tombs and a Mining Chest
- **Secrets and traps:** hidden rooms, false floors, mimics
- **Dungeon Maps**, a **Dungeon Compass**, **lore books**, **advancements** and an in-game manual, **The Delver's Companion**
- **Fully datapack-driven**, for modpack and datapack authors

Version 3.0.0 is a ground-up rewrite, built on Minecraft's own structure system. Dungeons are placed chunk by chunk, the way vanilla places villages and strongholds.

## Requirements

Dungeons2 3.0.0 runs on **Forge 1.20.1**, on both the client and the server.

| Mod | Version | |
|---|---|---|
| [GottschCore](https://www.curseforge.com/minecraft/mc-mods/gottschcore) | 2.9.0+ | Required |
| [DungeonBlocks](https://www.curseforge.com/minecraft/mc-mods/dungeonblocks) | 3.1.0+ | Required |
| [Gottsch's Monster Manual](https://www.curseforge.com/minecraft/mc-mods/gottschs-monster-manual) | 1.1.0+ | Required |
| [Treasure2](https://www.curseforge.com/minecraft/mc-mods/treasure2) | 4.1.0+ | Optional: the boss chest becomes a Treasure2 chest |
| Enemy Echelons API | 1.1.0+ | Optional: the dungeon's monsters get tougher the deeper you go |

**Gottsch Books** is bundled inside the jar, so there's nothing extra to install.
